Privacy Policy

Last updated: 14 October 2026

This policy covers the Google OAuth application n8n-scanner, operated by Mitchell Swapnil Chatterjee for personal workflow automation using self-hosted n8n.

Who uses the app

The app is used only by its owner. It is not offered to, or used by, any other person or organisation.

What Google data it accesses

  • Google Sheets and Google Drive: to read and write rows in spreadsheets owned by the account holder.
  • Gmail: to send automated emails (such as error alerts and test confirmations) from the account holder's own address.

How the data is used and stored

Data is processed only by the owner's self-hosted n8n instance to run the owner's own automations. OAuth tokens are stored in that instance and are not shared. No Google user data is sold, shared with third parties, or used for advertising.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time from the Google Account's security settings (Third-party apps & services).
